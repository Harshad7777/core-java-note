# What Is a Constructor?
A constructor is a special function in a class  :

1️⃣ Has the same name as the class

```java
class Student
{   // class name
    Student()
    {
        // constructor name = class name
    }
}
```

2️⃣ Has NO return type
Not even void.

3️⃣ Gets called automatically when an object is created
You don’t need to call it manually.

4️⃣ Used to initialize class members (variables)
**Example**
Student s = new Student();  // constructor is called here automatically

## Syntax of Constructor
### 1. Default / No-argument constructor
```java
class ClassName
{
   ClassName( )
     {
           // constructor
              // initialization code
        }
}
```

### 2. Parameterized constructor (accepts arguments)
```java
class ClassName
{
    ClassName(int x, String y)
     {
          // constructor with parameters
                // initialize variables
        }
}
```

💡 Example

```java
class Circle
{
   float PI, radius;
   Circle() //Default / No-argument constructor
   {

   }
   void setRadius(float radius)
   {
      this.radius=radius;
   }
   float getArea()
   {
     return radius*radius*PI;
   }
}
```
```java
public class CircleApplication
{
      public static void main(String x[])
     {
         Circle c = new Circle();
            c.setRadius(3.0f);
            float result = c.getArea();
            System.out.println("Area of circle is "+result);
     }
}
```

Note: if we not declare constructor within class then every class contain one default constructor added by java compiler known implicit constructor

## Q2. What is an Implicit Constructor?
If a class does NOT have any constructor → Java compiler automatically adds a default (no-arg) constructor.
✔ True: Every class contains an implicit constructor unless we create our own constructor.

A constructor that accepts arguments.

Used when:

Object MUST be initialized with dynamic / user-given values
Avoids using setters***

When pass parameter to constructor called as parameterized constructor when pass parameter to constructor we required to pass parameter where object created

Because when we create object using new keyword after new keyword there constructor calling point and constructor is also function and when we want to pass parameter to function need to pass at calling point and constructor calling is object so need to pass parameter to object creation

When multiple constructors have:

Same name

Different parameters / different data type /  different sequence of  parameter / count

## Q7. What is Constructor Chaining?
Calling one constructor from another.

Constructor chaining means when a class has multiple constructors and one constructor calls another constructor using this() (or parent constructor using super()) without using the new keyword.

🔍 Why we DON'T use new?
Because the object is created only once.
Constructors are called in chain, not new objects.

Two ways:
1️⃣ this() → call constructor inside same class using a constructor overloading technique
2️⃣ super() → call constructor of parent class / we will discuss this point in inheritance chapter

No.

## Q10. Can a constructor be static?
A constructor cannot be static because static members are loaded before objects are created,
while constructors run only when an object is created.
Their behaviors are opposite, so Java does not allow static constructors.

```java
class A
{
    static A()
    {
        System.out.println("Hello");
    }
}
```

## Q13. What is a Singleton Class?
A class that allows only ONE object in entire application.

Steps:

Private constructor
Private static object reference
Public static method returning that object

If we want to create a singleton class in Java we have some important steps.
1.    Declare class with private constructor

```java
class S
{
  private S()
  {
     System.out.println("I am constructor");
  }
}
```

2. Declare same class reference in it with private static and null

```java
class S
{
  private static S s1 = null;
  private S()
  {
     System.out.println("I am constructor");
  }
}
```

Create one static method and return reference of object by checking some condition

```java
class S
{
    private static S s1 = null;

    private S()
    {
           System.out.println("I am constructor");
    }

    public static S getInstance()
    {
        if (s1 == null)
            s1 = new S();

        return s1;
    }
}
```

```java
public class SCAPP
{
    public static void main(String x[])
    {
        S s1 = S.getInstance();
        S s2 = S.getInstance();
        S s3 = S.getInstance();
    }
}
```

## Q14. Can a constructor be final?
❌ No.
Reason: Final prevents overriding; constructor cannot be overridden.
## Q15. Can a constructor be abstract?
❌ No. get compile time error
Reason: Abstract means incomplete; constructor must be complete.
## Q16. Can a constructor be overridden?
❌ No.
Constructor is not inherited, so overriding is impossible.
## Q17. Difference between Function and Constructor
| Function | Constructor |
| --- | --- |
| Can have any name | Must be same as class name |
| Must have return type | No return type |
| Can be static | Cannot be static |
| Called manually | Called automatically |
| Used to write logic | Used to initialize object |
| Can be final | Cannot be final |
| Can override | Cannot override |
| Supports recursion | Constructor cannot |
